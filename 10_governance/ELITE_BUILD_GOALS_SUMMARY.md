# Elite Build Goals Summary

Source authority: `10_governance/source_of_truth/Elite_Build_Goals_v3.md`.

Meta Goal 0 and the 16 Elite Build Goals are permanent initialization and release standards. Classify each product goal as Universal, Conditional, Risk-Triggered, or Not Applicable before implementation or release.

## Meta Goal 0 — Deterministic Autonomous Initialization

Before architecture, implementation, deployment, or launch work, the EOS must be delivered, transferred to the Controller, initialized, and evidenced. It must:

1. not depend on the user knowing an internal file name;
2. not depend on voluntary repository exploration where a native delivery mechanism exists;
3. never continue silently when a mandatory input cannot be loaded;
4. report delivery environment, substantiated activation tier, Kernel and Controller version, capability resolution, degradations, and active controls;
5. confirm all 16 goals have an execution and verification path or name the gap;
6. block production implementation until pre-build gates pass;
7. never report a best-effort tier as enforced; and
8. distinguish activation from initialization.

A build satisfying all 16 goals while Meta Goal 0 was never satisfied is unverified because the controls were never demonstrably active.

## Mandatory Application

For every material task:

- establish Meta Goal 0 before project work;
- name applicable goals;
- state applicability;
- identify release blockers;
- map material claims to evidence;
- report remaining risk and owner;
- refuse to mark `Done` while an applicable release blocker remains.

## Non-Negotiable Guardrails

- Inspect before changing.
- Do not invent.
- Do not broaden scope silently.
- Do not bypass controls to obtain a pass.
- Do not claim unrun verification.
- Do not treat absence of evidence as success.
- Do not perform irreversible work without authorization and rollback planning.
- Do not expose secrets or private data.
- Do not create a second source of truth without an approved reason and migration plan.
- Do not mark work Done while release blockers remain.

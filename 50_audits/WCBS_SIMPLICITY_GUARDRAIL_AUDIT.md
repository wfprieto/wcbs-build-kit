# WCBS Build Kit: Simplicity Guardrail Audit

APIVR tier: Comprehensive. This is a kit-governance and reusable-skill
change with broad routing impact but no production or application mutation.
Evidence states follow WCBS: `Verified`, `Likely`, `Suspected`, `Unknown`,
`Not Run`, and `Blocked`.

## Objective and scope

Determine whether WCBS has an active owner for choosing the simplest safe
engineering design and challenging unjustified complexity. The scope is the
portable skill, activation/routing, generated catalog, load order, audit
evidence, and tests. The scope excludes the Destruction Analysis application,
CodeSapper implementation, production systems, and runtime superiority claims.

Canonical authority remains `00_start_here/SOURCE_OF_TRUTH.md`, APIVR, the
Elite Build Goals, and the numbered governance layers. This audit does not
replace them or create a second lifecycle.

## Simplest safe remediation

Add one specialist skill, `skills/simplest-safe-path/SKILL.md`, and wire it to
the existing system:

1. Extend the existing `needs-release` capability route with design-complexity
   subcapabilities and the new required skill, preserving the 20-capability
   vocabulary budget.
2. Add the skill to the canonical V2 specialist catalog and regenerate derived
   metadata.
3. Add it to the design, audit, and plan portions of `LOAD_ORDER.md` and the
   first-use guidance in `START_HERE.md`.
4. Keep APIVR, TDD, review, release, and 20-pass ownership unchanged.
5. Record the current-kit IDOR applicability result separately so a generic
   web-security audit is not confused with an application finding.

No new service, dependency, retry loop, runtime adapter, agent role, or
parallel governance layer is justified by this gap.

## Activation contract

The skill activates when a task has multiple viable designs, proposes a new
guardrail/stage/retry/fallback/dependency/abstraction/configuration surface,
or reviews an artifact for overengineering. It remains subordinate to
APIVR and the security tier router. A predetermined narrow edit does not gain
extra ceremony unless a design choice appears.

Required output: chosen simplest safe option, alternatives, complexity budget,
guardrail justifications, evidence states, APIVR verdict, and one next action.
